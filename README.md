# ДревМастер — Astro

Статическая версия сайта `derevo18.com` на Astro и React. Контент и изображения хранятся в репозитории, формы работают в демо-режиме и не отправляют данные.

## Команды

- `pnpm dev` — локальная разработка.
- `pnpm test:all` — lint, unit-тесты, статическая сборка и Playwright.
- `pnpm build:preview` — сборка тестовой среды Cloudflare с запретом индексации.
- `pnpm build:production` — production-сборка для `derevo18.com` с разрешённой индексацией.
- `pnpm deploy` — сборка и публикация тестовой среды через Wrangler.

Обе сборки создают один и тот же статический каталог `dist/`. Параметры окружений перечислены в `.env.example`.

## Управление контентом

Контент редактируется через [Pages CMS](https://app.pagescms.org/) в репозитории `metelev18/derevo18`. Интерфейс CMS описан в `.pages.yml`: одиночные страницы защищены от удаления, а записи каталога, портфолио, новостей, отзывов и материалов можно создавать, редактировать и удалять.

Новые изображения загружаются в `public/media` и сохраняются в контенте как пути `/media/...`. Видео добавляются ссылками для встраивания Kinescope; большие видеофайлы в репозиторий загружать не следует. Поле «Позиция в списке» управляет порядком карточек: меньшее число выводится выше.

Pages CMS сохраняет изменения непосредственно в GitHub. Появление изменений на опубликованном сайте зависит от настроенного процесса сборки и публикации.

Подключение кнопки генерации черновиков новостей через Yandex AI Studio описано в [docs/ai-news-generation.md](docs/ai-news-generation.md).

## Публикация

GitHub Actions проверяет каждое изменение и автоматически публикует ветку `master` в тестовую среду Cloudflare. Публикация production-версии в Yandex Object Storage запускается вручную после проверки тестовой среды.

## Структура

- `src/layouts` — базовый HTML/SEO-layout и общий layout сайта.
- `src/components/site` — шапка, подвал, контакты, формы и виджет связи.
- `src/components/home` — блоки главной страницы.
- `src/components/history` — интерактивная галерея страницы истории компании.
- `src/components/catalog` — каталог, карточки проектов и общие шаблоны проектных страниц.
- `src/components/portfolio` — сетка выполненных работ и полноэкранные фотогалереи.
- `src/components/news` — список публикаций и полноэкранные страницы статей и видео.
- `src/components/reviews` — список отзывов и полноэкранные страницы с текстом, фотографиями и видео.
- `src/components/materials` — сетка строительных материалов и полноэкранные статьи.
- `src/content` — Astro Content Collections: отдельные JSON-записи разделов и общие настройки.
- `src/content.config.ts` — схемы и загрузчики коллекций, проверяемые при сборке.
- `src/data` — типы, функции выборки и совместимый слой доступа к коллекциям.
- `public/media` — локальные изображения.

Статические секции выводятся Astro без клиентского JavaScript. React используется только для меню, форм, галерей, каруселей и других интерактивных блоков.

Готовые маршруты: главная `/`, история компании `/history/`, каталоги домов `/catalog-house/` и бань `/catalog-sauna/`, 41 карточка проекта, портфолио `/portfolio/` с 36 галереями, блог `/news/` с 20 публикациями, отзывы `/rewies/` с 33 публикациями и материалы `/material/` с 7 статьями. Остальные разделы пока ведут на локальную страницу-заглушку.
